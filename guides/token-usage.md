# Token Usage and Monitoring

Token consumption in Antigravity (`agy`) depends on repository size, task complexity, the number of spawned subagents, and context caching.

## How Antigravity Logs Token Usage

Antigravity logs session events and step metrics to:
```text
~/.gemini/antigravity-cli/brain/<conversation-id>/.system_generated/logs/transcript.jsonl
```

Every model interaction turn contains three core token counts:
- `input_tokens`: Non-cached prompt tokens processed.
- `cache_read_tokens`: Tokens retrieved from Antigravity's context cache.
- `output_tokens`: Completion and thinking tokens generated by the model.

Subagents spawned via `invoke_subagent` create their own conversation transcripts in the brain directory, linked through tool calls in the parent transcript.

## Using `scripts/token_usage.py`

`agy-orchestrator` ships with a dedicated token aggregation utility:

### 1. Inspect the Most Recent Session

```bash
python3 scripts/token_usage.py --latest
```

Outputs an aggregated markdown summary of total token consumption across the root orchestrator and all linked subagents.

### 2. List Recent Sessions

```bash
python3 scripts/token_usage.py --list
```

Optional date filtering:
```bash
python3 scripts/token_usage.py --list --date 2026-10-03
```

### 3. Inspect a Specific Session

```bash
python3 scripts/token_usage.py --root <conversation-id-or-prefix>
```

### 4. Machine-Readable JSON Output

```bash
python3 scripts/token_usage.py --latest --format json
```

## Optimizing Token Consumption

1. **Leverage Cache Reads:** Antigravity automatically caches stable repository context across turns. Avoid mutating unrelated files so cache read efficiency stays high.
2. **Keep Explorer Bounded:** Instruct explorers to return concise symbol references and file line ranges rather than echoing entire file contents back into the root context.
3. **Use Flash Tier for Routine Tasks:** Running `gemini-3.8-flash-high` for explorers and testers keeps token costs negligible while maintaining high speed.
